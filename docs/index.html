Frequently asked

How do I start a game?

Tap Start a game on the welcome screen. You'll get a 4-character code to share with the rest of the table — anyone with the code can join from Join a game on their own phone.

Someone made a mistake mid-hand. Can we fix it?

Yes. The host has an Undo button at the top of the hand screen. It rewinds the most recent action — the last bet, fold, check, or showdown winner pick. Tap it again to undo more.

The host's phone died. What now?

Re-opening the app on the same device restores host powers automatically. If the phone is gone for good, the table can't continue — settle up at the table from the chip counts shown on everyone else's phones.

Does PokerStacks deal cards?

No. PokerStacks tracks chips, pots, and bets only. Use a real deck and let the players decide who won — the app distributes the pot accordingly.

Is my data shared anywhere?

PokerStacks doesn't collect personal information. There's no sign-in, and no card data is ever stored. Game state lives on the app's backend (Convex) only as long as the session is active.

Reporting a problem

The fastest way to get a bug fixed is to open an issue on GitHub with:

  • What you were doing when it happened
  • What you expected to happen
  • What actually happened
  • Your device + OS version (e.g. iPhone 15, iOS 18.1)
